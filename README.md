# Kayan Graduation Experience

cria um convite digital de graduacao para a Kayan, de primeira vista o convite seria um portal com cadiado a baixo, quando eu partilhar o link aos convidados o convite sera capaz de identificar o convidado se é legivel ou nao, no portal inicial ira aparecer a imagem dela com uma descrisao, Graduada Dra Kayan, na base inferior iras aparecer um cadeiado onde se o convidado é legivel o cadiado estara aberto e tera uma indicaçao para clicar no cadiado, apos o cadeiado abrir, o convidado podera, ver o seu nome, mesa se for atribuido pelo admin, mapa de local do evento, dar presente, confirmar presença, ver fotos da graduada momento historico da jornada estudantil, um icon de camera para tirar fotos durante o evento e enviar serao demostradas na tela gigante em forma previa de brinde por alguns segundos e desaparecera voltara a mostrar o conteudo normal, na mesma vertende o convidado podera escrever felicitacoes que serao enviadas de forma poup brind na tela, garantindo uma experiência interativa e personalizada para todos os presentes. a outra parte do sistema sera uma pagina de borda de 1920 x 1080 para a transmisao de videos ao vivo, fotos que serao feitas upload com o admin, essa pagina sera responsavel de tramitir o conteudo que sera projetado na tela gigante, tdos brindes que o convidado mandar serao mostrados de forma de anuncios, quando chegar o momento de dança/... o amin podera escolher o que passa na tela,nesse caso o admin controla mais a tela. faca o appweb usando a imagem que mandei, use as cores como referencia, fundo transparente, modos dark e claro as cores principais sao amarelo dourado, azul escuro e preta.

Cria o layout as funcionalidades dos links depois faremos.
